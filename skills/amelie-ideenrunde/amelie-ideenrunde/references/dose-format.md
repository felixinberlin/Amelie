# Dose (Einseiter) — Format

Nur verwenden, wenn der Nutzer ausdrücklich eine Dose packen will. Vollständige Vorlagen und Mailtexte stehen in `amelie-vorlagen.md` im Projekt; bei Abweichungen gilt die Projektdatei.

Eine Seite. Dateiname `dosen/<slug>.md`.

```markdown
# <Name>

**Ein Satz:** <Was es ist, ohne Adjektive.>
**Stand:** <Datum> · **Prüfen ab:** <Datum + 12 Monate, Tooling + 6>
**Empfänger:** <Organisation / Mensch> · nachrangig: <…>
**Verdikt:** 🎁 verschenken | 🔨 erst Skelett | 🔒 behalten

## Das Problem
## Warum das jetzt geht
## Skizze            (inkl. was NICHT dazugehört)
## Erster Schritt    (ein Ticket, mit „fertig, wenn")
## Wo es kippt       (nie weglassen)
## Wer es schon versucht hat   (Pflicht — Ergebnis aus dem Prüfprotokoll)
## Vorarbeit

---
Diese Idee gehört niemandem. Nimm sie, bau sie, verkauf sie — du schuldest mir
nichts, nicht einmal eine Antwort. Wenn du eines Tages eine Idee hast, die du
nicht bauen wirst, gib sie jemandem, der es tut.
CC0 / Public Domain. — Félix, Berlin · github.com/felixinberlin
```

Name drunter, keine Bedingungen, kein Nachfassen.
