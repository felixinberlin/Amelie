# Dose: Automated Dual-License Contributor Agreement & SPDX Drift Sentry
**Domäne:** git (CC0 1.0 Universal)
**Zielinstitution:** Free Software Foundation Europe (FSFE) & Open Source Initiative

## Problemstellung & Evidenz
Tracks subtle licensing shifts and non-reciprocal re-licensing risks across deep dependency trees before commit time.

## Hypothese
Corporate open source maintainers increasingly relicense submodules without explicit notice to academic research contributors.

## Architektur
Reine Client-seitige Zero-Drift Micro-Engine für öffentliche Verwaltungen und Wissenschaft.
