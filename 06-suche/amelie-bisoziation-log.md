## Colliders that yielded

- **KI-gestützte Sportwertung (Turnen/Eiskunstlauf, Fujitsu-Motion-Capture-System)** — Distanz 4. Ergiebig, weil die Trennung "Sensor misst das Mechanische, Mensch urteilt über den Rest" direkt auf Kartierschlüssel übertragbar ist, deren Kriterien selbst in ein hartes (Struktur: Höhe, Deckung, Schichtung) und ein weiches (Artdiagnose, Gesamteindruck) Bündel zerfallen. Ertrag: 2 von 3 Überlebenden direkt aus dieser Trennung. Dritter Kandidat (Strukturmonitoring per LiDAR) kam aus demselben Friktionspunkt, war aber schon zu nah an aktiver Forschung — Warnsignal: dieselbe Friktion kann sowohl eine Lücke als auch (wenn die Technik billig genug ist) bereits ein besetztes Forschungsfeld freilegen.
- **Ant stigmergy** (biology, distance 5) — against a Type B citizen-science anchor (fireball witness reporting), it produced the gap between asynchronous/passive corroboration and real-time/active corroboration. Two clean survivors. Worth trying against a *different* Type B anchor to see if the same "make the passive step active/real-time" move generalizes.
- **Ant stigmergy** (biology, distance 4) — against a *different*, Type A anchor (municipal tree inspection) the same collider did **not** yield: both candidates died to the same fact, that "physical asset + recurring legal inspection duty + AI" is already a fully built-out vendor category in 2026 (see Atlas). Note the contrast with the distance-5 row above — same collider concept, different anchor type, opposite outcome. Two independent researchers picked "ant stigmergy" the same day without coordinating; worth flagging in the mode-list/collider-choice step so it isn't picked a third time before trying something else.

### Run 1 — 18.09.2026 (Researcher #4, lacunar-bisociation — Eichflächen/Kartierlotse)
- **Learned:** Der stärkste Überlebende kam nicht aus der auffälligsten Friktion (Sensor vs. Urteil), sondern aus der unauffälligsten: A's Ritual-Slot ("einmal pro Jahrzehnt, solistisch, Wissen stirbt mit dem Kartierer") gegen B's Ritual-Slot ("jede Saison neu kalibriert, Wissen ist ein Trainingskorpus"). Die Wettkampf-Domäne hat für fast jedes Problem, das sie löst, ein Trainings-/Kalibrierungs-Äquivalent — das ist ein wiederverwendbares Muster, nicht nur ein Zufallstreffer.
- **Mistake:** Zwei der ursprünglich stärksten Kandidaten (phone-LiDAR-Strukturerfassung, Strukturmonitoring zwischen Kartierzyklen) klangen beide originell, kollidierten aber mit demselben aktiven Forschungsfeld (Smartphone-LiDAR für Vegetationsstruktur, 2025/26). Hätte mit einer einzigen Suche *vor* dem Ausformulieren beider Kandidaten geprüft, ob "Smartphone LiDAR Vegetation" schon Preprints hat — hätte eine Suche gespart und früher auf den Trainings-/Kalibrierungs-Friktionspunkt fokussiert.
- **Next time:** Bei Distanz-4-Collidern aus dem Bereich "geübte, gemessene Leistung" (Sport, Musik, Handwerk) zuerst den Ritual-/Zeitachsen-Slot kollidieren, nicht den Material-/Sensor-Slot zuerst — Sensor-Kollisionen laufen zu oft in bereits aktive Forschung, Zeitachsen-Kollisionen (wie oft, wie einsam, wie wird kalibriert) treffen öfter auf echte organisatorische Lücken.

### Run 3 — 18.09.2026 (Researcher #3, method A/B test — Feuerkugel-Sofortnetz)
- **Learned:** Following the Run 0 retro (Type B anchor) but pushing distance to 5 instead of 4 worked well here — "ant stigmergy" vs. "citizen fireball reporting" produced two genuinely non-obvious survivors and two clean kills, not a pile of unusable noise. Distance 5 didn't degrade into nonsense when the anchor was concrete and well-documented (AMS/IMO process, stated explicitly as non-real-time).
- **Learned:** Two of the four tail-sampled candidates (radio-scatter correlation, phone infrasound) turned out to already exist at the institutional/citizen-science level (FRIPON, RedVox) — both were still non-obvious enough to not be on the mode list, which suggests the *mode list* and *occupied territory* are genuinely different filters: an idea can be simultaneously "no LLM would guess this first" and "already built by a specialist community." Both checks are needed, not just one.
- **Mistake:** Nearly packed the two survivors as separate one-page tins; on reflection they share one recipient class (fireball citizen-science networks: AMS/IMO/GMN) and one "why now," so bundling them as two Bausteine of one tin was the better match to Amélie rule 1 (matching is the work) than two thin cans.
- **Next time:** Try a Type A or C anchor instead of Type B (already used twice in this log's two runs so far) to see if the ant-stigmergy-style "passive→active, batch→real-time" collision move still produces survivors outside citizen-science pipelines — e.g. against a public AI trial (Type C) with a named async bottleneck.

### Run 4 — 18.09.2026 (Researcher #4-b [session 208a0f], bisociation A/B arm — Baumkontrolle/Baumkataster)
*Übernommen aus dem unkommittierten Worktree, siehe Notiz oben bei den Frame pairs. Umbenannt von „Run 1" auf „Run 4", weil zwei verschiedene Sessions unabhängig beide „Researcher #4" hießen und beide „Run 1" schrieben — Namenskollision, hier vom Librarian anhand des Session-Refs aufgelöst, Inhalt unverändert.*
- **Learned:** Deliberately picked a Type A anchor + distance-4 biology collider instead of the Run-0-suggested Type B/distance-4, specifically to avoid converging with the other bisociation researcher on the same pair. The friction decomposition (A: scarce credentialed inspector, static-once-recorded, invisible-in-situ record, fixed calendar vs. B: cheap continuous distributed re-marking, self-decaying record, legible in place, effort proportional to real traffic) produced several genuinely lacunar gap sentences, not a rehash of the mode list (CV photo apps, drone NDVI, IoT tilt sensors, crowdsourced hazard reports, acoustic tomography — all banned upfront). Two of those gaps were concrete enough to reality-check and both died to the *same* underlying fact: "urban tree + AI/photo" turned out to be a fully built-out commercial category in 2026 on every axis tried — legibility-in-place (QR plaques + portals: baumplaketten.de, BaumDex, Baumsicht, CheckTrees), *and* repeat-photo change/decay detection (Tree Inventory AI, greehill, ArboStar, TreeTect). That is a stronger, more specific Atlas signal than "German civic + PR angle is dicht" — it's now "German civic + **an inspectable physical asset with a recurring legal check** is dicht end to end," which likely also covers playgrounds, lifts, fire extinguishers, bridges (see Atlas update in `amelie-suchplaybook.md`).
- **Mistake:** For the first candidate, went straight from friction to a single strong-seeming candidate and existence-checked it before generating the full 10–20 candidate pool the protocol calls for (session was cut short by a team-wide restart mid-protocol, then resumed on user request). Even after resuming, checked a second candidate from the *same* anchor/domain rather than first testing whether the anchor itself was already exhausted — two searches into the same anchor both independently surfaced the same commercial category, which in hindsight one Atlas-style pre-check ("does an 'AI + tree inspection' vendor category already exist?") would have flagged before spending a second search.
- **Next time:** (1) After the *first* checked candidate from an anchor dies to a whole vendor *category* (not just one competitor), treat that as evidence the anchor itself is dicht and pivot the anchor before trying a second candidate from the same source — don't spend a second search confirming the same market. (2) Any Type A anchor that is "a physical asset + a recurring, legally-mandated visual/manual check" (trees, playgrounds, elevators, fire extinguishers, bridges, playground equipment per DIN 1176) should be assumed AI-vendor-crowded by default in 2026 and checked against the Atlas before the collision step, the way citizen-science (Type B) already is. (3) Try the stigmergy collider (legible-in-place vs. siloed-database record) again on a domain *without* an existing inspection-software industry — e.g. informal/undocumented infrastructure (Trampelpfade, self-organized Schrebergarten rules, Kiez-level mutual aid) where no vendor has already industrialized the "digitize the inspection" move.
