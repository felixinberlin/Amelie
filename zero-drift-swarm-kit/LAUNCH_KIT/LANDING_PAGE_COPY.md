## The Solution: Zero-Drift Swarm Architecture
The **Zero-Drift Swarm Kit** is an opinionated, production-tested repository blueprint that enforces strict software engineering discipline on autonomous AI agent teams.

### 1. The Single-Writer Principle ("The Librarian")
Subagents run in parallel to research, stress-test, and benchmark. But **only one designated agent** is permitted to touch shared memory, registry indexes, and state files. 
- Result: **Zero git conflicts, zero state corruption.**

### 2. Mechanical Drift-Guards Over Prompt Politeness
Never rely on prompt politeness (*"Please remember to update the docs"*). Our deterministic `npm run lint` guards compare markdown specifications against code registries on every step and halt execution before token waste occurs.

### 3. The Graveyard Protocol (Backward Memory)
Agents keep repeating mistakes because context windows forget failures. Our structured autopsy protocol gives every dead approach a machine-readable death certificate. Before starting any task, agents cross-check the Graveyard. **No zombie ideas.**

### 4. Multi-Engine Convergence Over Scoring
Instead of asking an LLM *"is this code good?"*, the kit launches 3 distinct discovery angles in parallel. An approach is only accepted if independent agents converge on the same solution.
